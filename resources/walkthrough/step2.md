## Open Forge

**Click the Forge mark in the activity bar** to open the chat sidebar.

Or use the keyboard:

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Focus the Forge input | `Ctrl+Escape` | `Cmd+Escape` |
| Open Forge in a new tab | `Ctrl+Shift+Escape` | `Cmd+Shift+Escape` |
| Insert an @-mention for the current file | `Alt+K` | `Alt+K` |

Every one of these is also in the Command Palette under **Forge:**.
