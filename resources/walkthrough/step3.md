## Chat with Forge

**Type a message and press Enter.** Forge can explain code, fix bugs, write
features, refactor, and run terminal commands.

**Pull files into context with `@`.** Type `@` in the input to search your
workspace, or press `Alt+K` with a file open to insert a reference to it. Select
lines first and the mention carries the line range with it.

Tool calls stream in as they happen, and anything that touches your files asks
for permission before it runs.
