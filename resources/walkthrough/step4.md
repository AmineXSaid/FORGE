## Past conversations

**Your conversations are saved as you go.**

- **Forge: Past Conversations** opens the session list in an editor tab.
- **Forge: New Conversation** starts a fresh one.
- **Forge: Open in New Tab** gives a conversation its own editor tab, so you can
  keep several going side by side.

The `Ctrl+N` / `Cmd+N` shortcut for a new conversation is off by default, because
it shadows the editor's New File binding. Turn it on with
`forge.enableNewConversationShortcut`.
